# Organic Juicy

Небольшой учебный лендинг для бренда органических соков с адаптивной версткой, бургер-меню и двумя слайдерами на JavaScript.  
Проект сделан на чистом HTML, CSS и JavaScript без сборки.

## Демо

https://sxnizh.github.io/juicy-landing/

## Технологии

- HTML
- CSS
- JavaScript

## Что есть в проекте

- адаптивная сетка на CSS Grid
- бургер-меню для мобильной версии
- слайдер с переключением по стрелкам
- слайдер с навигацией по точкам
- адаптивная верстка под разные размеры экрана
- секции с изображениями и текстовыми блоками
- футер с формой подписки и соцсетями
- hover-эффекты для кнопок, ссылок и иконок

## Как запустить

1. Клонировать репозиторий

```bash
git clone https://github.com/sxnizh/juicy-landing.git
```

2. Открыть папку проекта

```bash
cd juicy-landing
```


3. Открыть `index.html` в браузере
